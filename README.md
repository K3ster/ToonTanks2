# ToonTanks2

**ToonTanks2** to prosta gra czołgowa stworzona w Unreal Engine 5 z wykorzystaniem języka C++. Projekt ten ma na celu naukę podstaw tworzenia gier w Unreal Engine oraz implementacji logiki gry za pomocą C++.

## Rozpoczęcie pracy

Aby uruchomić projekt lokalnie, wykonaj poniższe kroki:

1. **Klonowanie repozytorium**: Sklonuj repozytorium na swój lokalny komputer:
   ```bash
   git clone https://github.com/K3ster/ToonTanks2.git
   ```

2. **Otwieranie projektu**:
   - Upewnij się, że masz zainstalowany Unreal Engine 5.
   - Otwórz plik `ToonTanks.uproject` za pomocą Unreal Engine.

3. **Kompilacja projektu**:
   - Jeśli to konieczne, wygeneruj pliki projektu dla swojego środowiska IDE (np. Visual Studio) klikając prawym przyciskiem myszy na plik `ToonTanks.uproject` i wybierając opcję "Generate Visual Studio project files".
   - Otwórz wygenerowany plik projektu (`.sln`) i skompiluj go w wybranym IDE.

## Struktura projektu

- `Source/`: Katalog zawierający kod źródłowy gry napisany w C++.
- `Content/`: Katalog z zasobami gry, takimi jak modele, tekstury i dźwięki.
- `Config/`: Pliki konfiguracyjne projektu.

## Wymagania

- Unreal Engine 5
- Środowisko programistyczne zgodne z C++ (np. Visual Studio)
